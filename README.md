## 🚀 **O Nascimento do -Lab**

O **-Lab** surgiu como uma iniciativa do **Professor Corrêa** para criar um **espaço de experimentação e aprendizado** focado em bibliotecas, ferramentas e frameworks. Cada repositório que leva o sufixo **-lab** representa uma aplicação simples, prática e direta, projetada para **explorar, aprender e documentar** o funcionamento de uma tecnologia específica.

O objetivo é fornecer um **ambiente claro e acessível** para estudantes, desenvolvedores iniciantes e curiosos mergulharem em tecnologias modernas sem distrações ou configurações excessivas.

---

## 🐻 **O que é Zustand?**

**Zustand** é uma biblioteca de gerenciamento de estado para **React**, conhecida por ser **leve, direta e fácil de usar**. Ela elimina a necessidade de configurações complexas, comuns em soluções mais robustas, e permite que você gerencie o estado global com uma API simples e intuitiva.

### ✅ **Por que usar Zustand?**

- **API Direta:** Menos código boilerplate.  
- **Performance:** Evita re-renders desnecessários.  
- **Escalabilidade:** Adequado tanto para pequenos componentes quanto para aplicações grandes.  
- **Flexível:** Pode ser combinado com outras bibliotecas e abordagens.  

---

## 📚 **Sobre o Repositório**

Este repositório **\`zustand-lab\`** foi criado para explorar os conceitos básicos do **Zustand**, com exemplos claros de como:

- Criar uma **store** (loja de estado).  
- Assinar e manipular o estado global.  
- Usar ações para atualizar estados.  

Cada funcionalidade foi implementada de forma simples, para que você possa entender os princípios fundamentais sem distrações.

## 🛠️ **Como Executar o Projeto**

1. Clone o repositório:

```bash
git clone https://github.com/lucascorreaa/zustand-lab.git
```

2. Instale as dependências:

```bash
yarn
```

3. Inicie o servidor de desenvolvimento:

```bash
yarn dev
```

4. Acesse no navegador: [http://localhost:5173](http://localhost:5173)
